2요청 원문

주문 취소 시 데이터를 삭제하지 않고 이력을 남길 수 있도록 수정해줘. 그리고 주문상세 화면에서 삭제 후 해당화면에 머무르고있으면서 주문내역이 없다고 표시하는 것보다 다시 목록화면으로 이동시키는게 좋을 것 같아.

3이해 점검

배경 · 어떤 상황인가✓ 이해함

OrderService.changeStatus 는 CANCELED 로 바꾼 뒤 orders.delete(order) 로 주문 행을 지웁니다. 이후 상세 화면(order-detail.js)은 load() 에서 주문 조회에 실패해 '주문을 찾을 수 없습니다' 오류만 보여 줍니다.

근거: OrderService.java:114-116 · order-detail.js changeStatus/load · order-status.spec.ts STS-05(test.fail) · INTENT.md 28행

목적 · 왜 필요한가✓ 이해함

취소 주문을 취소 상태로 목록에 남겨 이력과 건수를 확인할 수 있게 하고, 취소 직후 사용자를 목록으로 보내 막다른 오류 화면을 없앱니다.

근거: 요청 문장 · PRD.md 63-73행 · 목록 칩 '취소' (STS-05 기대)

7유형별 점검 기능 추가

취소 시 삭제하던 동작을 보존으로 바꾸고 취소 후 이동을 추가하는 의도적 동작 변경이므로 기능 추가로 판단했습니다. 취소 후 오류 화면은 STS-05 에 알려진 결함으로 적혀 있어 일부 버그 성격이 있으나, 요청이 정책 변경을 명시하므로 주된 종류는 기능 추가입니다.
