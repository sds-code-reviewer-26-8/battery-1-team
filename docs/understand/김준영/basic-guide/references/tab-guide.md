# 3탭 구성 기준

각 탭은 질문 하나에 답한다. 탭 아래에 "다음 탭으로" 버튼을 둔다.

## 탭 1. 큰 그림 — "이게 뭐 하는 거야?"
- 한 문장 목적: 주문을 받아 공장별 생산량과 배 운항 계획을 대신 계산해 주는 프로그램.
- 등장인물 카드: 공장(중국·일본·베트남·인도네시아), 배, 주문, 한국(출발·도착지). 각 카드는 클릭하면 한 줄 설명이 열린다.
- 비유 하나(예: 택배 기사가 여러 도시 창고를 돌며 물건을 모아 오는 일).
- 인터랙션: 카드 클릭 → 설명 열기/닫기 (`data-card`).

## 탭 2. 사용 흐름 — "사람이 뭘 하지?"
- 단계: 로그인 → 수량 입력 → 세 가지 경로 비교 → 하나 선택해 확정 → 상태 관리.
- 단계 버튼으로 앞뒤 이동하며 단계마다 화면 그림(간단한 박스)과 설명 한두 줄.
- 주문 상태 체험: 확정 → 진행 → 완료/취소. 현재 상태에서 갈 수 있는 버튼만 켠다. 규칙은 현재 코드(`OrderStatus`)를 따른다.
- 인터랙션: 단계 이동(`data-step`), 상태 전이 체험(`data-status`).

## 탭 3. 계산 원리 — "컴퓨터는 어떻게 정하지?"
- 핵심 규칙 3~4개만: 공장마다 쌓아 둘 수 있는 양에 한도가 있다 / 한도를 넘으면 배가 여러 번 간다 / 경로는 싸게·빠르게·가까운 곳부터 세 기준으로 비교한다.
- 간이 계산기: 나라별 수량 슬라이더를 움직이면 "배가 그 나라에 가는 횟수"가 바뀐다. 횟수 = 올림(주문 ÷ 쌓아 둘 수 있는 한도). 공장 한도는 코드의 현재 기본값을 쓴다.
- 화면에 "간이 예시이며 실제 계산은 더 복잡합니다"라고 표시한다. 일수·비용까지 계산하려면 코드와 대조한 값만 쓴다.
- 확인 퀴즈 2~3문항(선택지 클릭 시 정답/해설 표시).
- 인터랙션: 슬라이더 계산기(`data-calc`), 퀴즈(`data-quiz`).
