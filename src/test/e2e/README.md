# E2E 테스트 (Playwright)

화면과 API 를 브라우저로 직접 확인하는 테스트다. `*.spec.ts` 를 이 폴더에 추가하면 자동으로 실행된다.

## 실행

```
cd src/test/e2e
npm install
npx playwright install chromium    # 처음 한 번
npm test                           # 전체 실행
npm run test:ui                    # UI 모드
```

- 앱을 미리 띄울 필요가 없다. 테스트가 시작될 때 **인메모리 DB**로 앱을 8091 포트에 새로 띄우고, 끝나면 종료한다. 개발 DB 에는 영향이 없다. (Java 17 필요, 기동에 20초 안팎, Windows 전용 명령)
- 8091 포트가 이미 사용 중이면 오류로 멈춘다. 포트는 `E2E_PORT` 로 바꿀 수 있다.
- `BASE_URL` 을 지정하면 그 서버를 그대로 쓴다. 이 경우 DB 는 그 서버의 DB 다.

## 작성 규칙

- **상대 주소**(`page.goto('/login')`)를 쓴다. 주소는 설정의 `baseURL` 이 채운다.
- 테스트는 **한 개씩 순서대로** 실행된다 (`workers: 1`). 마스터 데이터와 주문이 전역 상태이기 때문이다.
- 매번 **초기 상태**(마스터 초기값, 주문 0건)에서 시작하므로 초기값을 전제로 써도 된다. 마스터를 바꾸는 테스트는 끝에 원래 값으로 되돌린다.
- 테스트 제목에 시나리오 엑셀의 케이스 ID 를 넣는다. 예: `AUTH-02-TC01 admin 계정으로 로그인`
- 다른 사람이 같은 이름의 파일을 만들지 않도록 spec·헬퍼 파일 이름은 영역이 드러나게 짓는다.
